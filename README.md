
# Robotic Hand Project

**Overview:**  
Designed and 3D-printed a fully functional robotic hand, integrated with Arduino, servo motors, and flex sensors. The hand can be controlled wirelessly via cloud-based Wi-Fi using ESP32/ESP8266 modules and can also be operated through a glove interface, showcasing IoT and AI integration.

**Technologies Used:**  
- Arduino IDE  
- ESP32 & ESP8266  
- Flex Sensors  
- Servo Motors  
- C Programming  
- PHP  
- SQL Database  
- 3D Printing  

**Features:**  
- Fully functional robotic hand with precise servo movements  
- Wireless control through cloud services (Wi-Fi)  
- Glove-operated control for intuitive interaction  
- Real-time IoT communication  
- Integration with backend database and web interface  

**How it Works:**  
1. Flex sensors on the glove detect finger movements.  
2. Sensor data is sent via ESP32/ESP8266 to the cloud.  
3. Arduino interprets the data and moves the robotic hand accordingly.  
4. Servo motors perform accurate finger movements to mimic the glove.
